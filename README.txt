Package documentation adapted for stats.camp.

Can Incorrect Beliefs about the Racial Composition of Welfare and
Unemployment Insurance Beneficiaries be Changed?
Jeffrey Carpenter, Jakina Debnam Guzman, Peter Hans Matthews,
and Erin L. Wolcott

Overview

The code constructs the analysis contained in the manuscript. The authors
conducted two parallel, three-stage experiments on CloudResearch's Connect
platform between June and August 2024. The original authors estimated a run
time of three minutes; this is not a browser benchmark.

Data availability and provenance

Participants were U.S. adults. There were 3,029 participants in Stage 1,
2,834 in Stage 2, and 2,324 in Stage 3. Selected summary statistics from the
original documentation are reproduced below.

Instructions to replicators

1. Keep Carpenter_et_al_2025_Papers_and_Proceedings.dta in the repository root.
2. Open Carpenter_et_al_2025_Papers_and_Proceedings.do in stats.camp.
3. Run the .do file from the repository root. The original line-17 path
   placeholder has already been replaced with the repository-relative data
   path in this adaptation.
